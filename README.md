# BakeWise LK

Agentic AI Compliance & Pricing Advisor for Sri Lankan Home-Based Food SMEs.

## Problem
Home-based food entrepreneurs in Sri Lanka often lack clear guidance on:
- business registration
- food safety basics
- labeling and packaging
- pricing
- tax and compliance
- financing options

## Planned Features
- Multi-agent question answering
- Sri Lanka-specific RAG knowledge base
- Pricing calculator
- Compliance checklist
- Streamlit web interface

## Tech Stack
- Python
- Streamlit
- Groq
- ChromaDB
- Sentence Transformers
